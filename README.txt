송현 그룹 PT 홈페이지 소스
=============================

구성 파일
- index.html : 홈
- about.html : 센터 소개
- program.html : 프로그램
- coach.html : 강사진
- gallery.html : 갤러리
- contact.html : 상담 신청
- style.css : 모든 페이지 공통 CSS
- home.css / about.css / program.css / coach.css / gallery.css / contact.css : 페이지별 CSS

사용 방법
1. 압축을 해제합니다.
2. 모든 파일을 같은 폴더에 둡니다.
3. index.html을 브라우저에서 엽니다.
4. 메뉴를 클릭해 페이지 이동을 확인합니다.

수정해야 할 내용
- 센터 주소, 전화번호, 운영시간
- 실제 강사 이름, 프로필, 자격 및 경력
- 실제 시설 및 수업 사진
- contact.html의 YOUR_EMAIL@example.com 을 접수 이메일로 변경
- 실제 신청 접수를 위해서는 이메일 폼 대신 폼 서비스 또는 서버 연결 권장

참고
- 홈 화면의 이미지 슬라이더는 home.js로 동작합니다. 다른 페이지의 내비게이션은 nav.js를 사용합니다.
- 페이지 이동은 HTML의 a href 링크를 사용합니다.
- 홈의 움직임, 텍스트 등장, 슬로건 흐름은 CSS 애니메이션입니다.
- 이미지들은 예시용 외부 이미지 주소입니다. 실제 홈페이지 공개 전 사용 권한과 적합성을 확인하고 센터 자체 사진으로 교체하세요.
- 공공지원 사업의 비용이나 지원 조건은 확정된 실제 운영 정보로 입력해야 합니다.
