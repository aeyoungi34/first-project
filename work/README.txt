송현점 홈페이지 v2
- JavaScript를 사용하지 않고 HTML + CSS만으로 구성했습니다.
- index.html을 열면 홈 화면이 시작됩니다.
- 메뉴는 각각 별도 HTML 파일로 이동합니다.
- business.html / activity.html에는 브랜드 헤더를 제거하고 메뉴만 남겼습니다.
- 홈 운동 이미지는 현재 예시 URL 자리표시자입니다. 실제 이미지 주소로 교체하세요.
- 슈퍼바이저 사진 파일명: supervisor.jpg
- 강사/시설/활동 사진은 각 HTML의 img src에 적힌 파일명으로 같은 폴더에 저장하면 됩니다.
- 연락처/주소/신청 접수 기능은 기관의 실제 정보 및 접수 시스템에 맞춰 추가해야 합니다.
